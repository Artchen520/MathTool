# Obsidian数学公式编辑器

一个专为Obsidian用户设计的本地数学公式编辑工具，提供实时预览、快捷输入和主题切换等功能，帮助你更高效地编写和调试LaTeX数学公式。

## 功能特点

- **实时预览**：输入LaTeX代码时，右侧自动渲染公式效果
- **虚拟键盘**：底部提供分类快捷键，快速插入特殊符号（希腊字母、积分、矩阵等）
- **主题切换**：支持浅色/深色模式，自动保存用户偏好
- **常用公式**：预设常用公式库，一键插入（如二次方程、泰勒展开）
- **自定义公式**：支持添加个人常用公式，方便重复使用
- **快捷键支持**：提供丰富的键盘快捷操作（复制、清空、切换模式等）

## 使用方法

1. **基本编辑**
   - 在左侧输入框中键入LaTeX公式代码
   - 右侧实时预览渲染效果
   - 点击底部虚拟键盘的符号，插入对应LaTeX代码到光标位置

2. **公式格式切换**
   - 点击输入框标题栏的`$`/`$$`按钮，切换行内公式（`$...$`）或行间公式（`$$...$$`）

3. **常用公式**
   - 点击顶部「常用公式」按钮，从下拉菜单选择预设公式
   - 点击「添加自定义公式」保存个人公式

4. **主题切换**
   - 点击顶部「主题」按钮，在浅色/深色模式间切换

5. **快捷键**
   - `Ctrl+Shift+C`：复制公式到剪贴板
   - `Ctrl+Shift+Backspace`：清空输入框
   - `Ctrl+Shift+M`：切换行内/行间公式
   - `Ctrl+Shift+K`：折叠/展开虚拟键盘
   - `Ctrl+Shift+T`：切换主题
   - `Esc`：关闭弹窗/下拉菜单
   - 也可以自定义

## 技术说明

- 本地运行，数据不上传网络
